## 🎯 Aperçu du Projet

Ce projet a été conçu selon les standards du web moderne :
- **Design System Dark & Glassmorphism :** Palette sombre raffinée, contrastes travaillés, typographie *Syne* et accents bleu électrique / cyan néon.
- **Expérience Utilisateur Interactive :** Filtrage dynamique des projets en temps réel, animations fluides au survol, scrollspy pour la navigation et adaptation responsive complète (Mobile, Tablette, Desktop).
- **Architecture Modulaire :** Organisation claire des pages dédiées et compartimentage strict des assets statiques.

## 🚀 Démarrage en Local

Pour lancer et tester le portfolio en local sur votre machine :

```bash
# 1. Cloner le dépôt
git clone https://github.com/Grqeen/Portfolio.git

# 2. Accéder au répertoire
cd Portfolio

# 3. Lancer un serveur de développement local (au choix) :
# Avec Python :
python -m http.server 8080

# Avec Node / npx :
npx serve .
```

Ouvrez ensuite votre navigateur sur `http://localhost:8080`.
